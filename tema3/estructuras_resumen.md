\# Equivalencias Python ↔ R



\- array de NumPy ↔ vector de R: los dos guardan datos del mismo tipo, se arman con corchetes/función (np.array(\[...]) en Python, c(...) en R)

\- diccionario de Python ↔ argumentos con nombre en data.frame(): en Python uso un diccionario (clave = columna) para armar el DataFrame, en R pongo directo nombre = c(...) dentro de data.frame()

\- DataFrame de pandas ↔ data.frame de R: los dos son una tabla armada con columnas del mismo largo, cada una con su nombre

\- indexación con corchetes en Python ↔ indexación con corchetes en R: los dos acceden a un elemento con corchetes, pero Python arranca en el índice 0 y R en el 1
